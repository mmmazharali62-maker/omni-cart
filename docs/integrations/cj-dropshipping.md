# CJ Dropshipping Setup

CJ provides product import, per-item pricing, automatic ordering, and tracking.

## Get your credentials

1. Create an account at cjdropshipping.com.
2. Dashboard → **API** (under Developer) → apply for API access (usually instant).
3. Copy the **API key** shown there.
4. Use the same email you registered with.

## Apply it

Admin → Integrations → CJ Dropshipping: paste the API key and account email,
Save, then **Test connection**.

## What unlocks

- **One-click import**: paste any CJ product URL in Admin → Products → Import;
  title, images, variants, and inventory sync automatically.
- **Auto-fulfillment**: paid orders are placed with CJ automatically.
- **Tracking**: CJ tracking numbers flow into each order and trigger
  customer notifications.
- **Price sync**: a background job re-syncs supplier costs so the pricing
  engine can keep margins stable.

## Tips

- Keep 1-2 backup suppliers per bestseller.
- Check the CJ dashboard's shipping quotes for US/UK lines before pricing.
