# AliExpress Setup

AliExpress broadens the catalog and provides affiliate earnings on top of
product margin.

## Get your credentials

1. Sign up at portals.aliexpress.com (affiliate/dropshipper portal).
2. Apply for the **Dropshipper API** - approval typically takes 1-3 days.
3. Copy your API key from the portal's developer section.
4. Copy your affiliate **tracking ID** (optional but recommended: earns
  commission on orders sourced through AliExpress).

## Apply it

Admin → Integrations → AliExpress: paste the API key (and tracking ID), Save,
then **Test connection**.

## Notes

- The API is regional (US/EU endpoints); the app routes by the store's target
  market setting.
- Product import works like CJ: paste an AliExpress product URL in the admin
  import screen.
- Real-time shipping estimates come from the AliExpress logistics API when
  available, otherwise the default US/UK rates apply.
